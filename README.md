# Ália

Assistente pessoal (demonstração): agenda, finanças, viagens e um chat que aprende com você.

Abra o endereço no celular e instale: no Android (Chrome), menu ⋮ e "Instalar app"; no iPhone (Safari), Compartilhar e "Adicionar à Tela de Início".

Os dados ficam só no aparelho de quem usa. Não há conta nem servidor.
